# 0012 YoRHa 视觉底座与三阶段落地

Date: 2026-09-30

Status: Draft

应用此前是一套 shadcn + Linear 风格的主题（`--brand` 紫、Space Grotesk、8px 圆角）。用户在 Work 页原型的多轮评审中确立了 YoRHa 视觉语言，并明确它不能只停留在 Work 页成为「局部孤岛」，也不是把整套像素平铺到 Workset 工坊流程上。本记录确立：以「系统底座（tokens/原语）同构，业务心智（HUD/表单）分层」的方式分三个阶段落地。

**唯一视觉真相源**是已评审的原型 `work-wall-v5-2-yorha-refined.html`（open-design 项目 dorganizer-plan-7686，仓外文件）：其中每一个 token、尺寸与时长都是用户已确认的决定，不是起点建议。改动任何颜色前必须复验对比度（正文对 ≥ 4.5:1）。

## 1 三阶段

- **阶段 1（本次）**：`theme-yorha.css` 承载 YoRHa 原生 tokens 与原语类；`style.css` 把 shadcn 语义层与角色 tokens 全部改为指向 YoRHa 变量的间接引用 —— 现有全部页面不改 markup 即刻换上 YoRHa 色板/字阶/直角圆角。
- **阶段 2（本次）**：Work 页作为旗舰按原型完整落地（作品墙 + 检视舱 + 底边播放条 + 媒体库下拉），路由 `/works`、`/works/:rj`。
- **阶段 3（本次）**：AppShell 导航与 Workset 外壳、组件「战术化换肤」：只动容器观感、表格终止线、表单控件、按钮反色与选中高亮，**不推翻**既有业务交互流程（目录树、计划审阅、批量编辑表单）。先改共享原语（Button、下拉菜单、Modal/Sheet、Badge、Card），页面只做少量类名替换。

## 2 命名与不可逾越的保留色

- 原型的 `--accent`（陶土红）在本仓更名为 **`--now`**：`--accent` 在 shadcn 语义里是悬停面，两个语义不能共用一个名字。陶土红只归「正在播放」（NOW 标、播放中音轨标记、状态点、浅色激光），**绝不挪作他用**。
- 状态角色（success/warning/danger/info）保持字面色值，不并入 YoRHa 色板：它们是领域编码（状态永远不只靠颜色传达），其对比度记录见 `style.css` 注释。原 encode-state 的琥珀即存活于 warning 角色。
- 密度 token（`--row-h` 等）与 `--motion-*` 保持不变；YoRHa 动效时长（`--dur-*`、`--ease-*`）与其并行，页面按自己的语言取用。

## 3 字体三层矩阵

用户显式确认的选型，**覆盖原型的双字体方案**（原型只有 IBM Plex Mono + Zen Kaku Gothic New）：

- `--font-mincho`：Shippori Mincho（回退 Noto Serif JP → Noto Serif SC）—— **仅限作品标题**：作品墙卡片题（`.cap-title`）与作品详情展台标题（`.insp-title`）。明朝体是展示字，不承担任何界面职责。
- `--font-ui`：Noto Sans SC（思源黑体简体，回退 BIZ UDPGothic → PingFang SC → Microsoft YaHei）—— 正文、元数据、表单控件，以及全部界面标题：页面 h1/h2、弹窗与抽屉标题、目录树节点、空状态提示。`--font-heading` 指向此处，`font-heading` / `cn-font-heading` 因此是界面字而非展示字。中文字体必须居栈首：字体回退按家族命中而非字重，BIZ UDPGothic 自带 JIS 字形，放在前面就会拿下所有共用汉字（直/骨/者/次），中文优先也就无从谈起。
- `--font-mono`：IBM Plex Mono —— 标签（`.lbl`）、RJ 号、时间等遥测数字，全部 `tabular-nums`。

经 Google Fonts `@import` 切片加载；离线回退系统字体。此前的 Space Grotesk 实际上从未有任何加载来源，直接废弃。

## 4 已知边界

- 全局 `prefers-reduced-motion` 下一切过渡瞬时生效（原型原样）。
- 颗粒（grain）只铺底材，永不覆盖封面；45° 排线只用于空状态；双终止线只出现在外缘（顶栏下、底条上）。
- 播放条当前挂在 WorksPage 内（28px 行，高度由播放条自己定，页面网格只留 auto 行）；音频后端落地后可升级为 AppShell 的全局行。鼠标设备上播放条右侧有静音键与音量推子，音量与静音按浏览器记住（localStorage，读写失败即按满音量）；触屏（`pointer: coarse`）不显示音量——用设备自身音量，iOS 也不理会元素音量——改为 52px 高的播放条、44×40 的切轨键、56×40 的主键与 24px 高的拖动带，避免误触。
- **播放以作品的音轨队列为单位**：检视舱的音轨行、PLAY、作品墙的 P 与详情页的音轨都把整张音轨表交给播放器（检视舱与作品墙取各音轨的首个格式，详情页取所浏览的格式，缺该格式的音轨退回其首个格式），从所点的那一轨开始。一轨播完自动接下一轨，末轨播完即暂停；播放条的上一轨 / 下一轨在队列内移动，详情页的音轨高亮与歌词随之跟进。激光所在的进度线同时是拖动进度的滑块（原生 range，键盘可操作），只在时长已知时可用。没有音频文件的作品仍走静默时钟。
- **筛选栏偏离原型（用户已确认）**：原型的静态标签页换成三个下拉筛选——声优、社团（均可按名称检索，选项来自 ADR 0011 的筛选项清单）、年龄分级（全年龄 / R18 / 未申告；未申告是独立取值，不等于全年龄）——外加一个排序下拉（发售日 / 入库时间 / 个人评分，均为新→旧、高→低，未知值恒在末尾）。下拉沿用媒体库面板的标本样式：设了值的筛选读作按下的标签（反色），排序不反色。历史库的声优、社团可达上千项，故下拉列表虚拟化：无论开合，只绘制视口内的行（千项时打开从约 300ms 降到约 20ms，4 倍 CPU 降速下实测），键盘按序号移动、目标行先滚入再聚焦，打开时当前值滚到视口中央。
- **标签索引是弹窗而非下拉**：多选与 AND/OR 切换在下拉里放不下，故筛选栏的 TAG 标签页打开模态框（共享 Modal）。来源标签与用户标签按名称合并为一个选项，分「我的标签」「作品标签」两段、各按本词表的作品数降序（短而私人的「我的标签」在前，不压在来源词表数百项的长尾之下）；同名项在两段中是同一个选项，选中状态共享，各段只显示本词表的作品数，以免同一部作品被数两次。历史库可达数百个标签，故弹窗高度封顶于视口、只有两段标签滚动，检索框、模式切换与 APPLY 始终可见。弹窗内的勾选与模式切换只是暂存，APPLY 才生效，其余方式关闭即放弃。所选标签与模式和声优、社团一样写进作品墙的地址（见下条）；切换媒体库时清空。已选项不依赖当前清单：当前筛选下已无匹配、甚至名称都查不到的选项仍列在「已选」里（名称回退到按媒体库的清单，查不到时标「未知标签」），可单独移除；APPLY 保留所有未被取消的选项，名称解析失败不会丢掉选择。
- 控件边界另设 `--wire-control`（浅 `rgba(20,21,24,.5)`、深 `rgba(222,215,198,.45)`，各底色上 ≥ 3:1，记录见 `style.css`）：原型的 `--wire-mid` 只有约 2.4:1，作装饰线足够，作输入框与控件边界不达 WCAG 1.4.11。这是唯一不来自原型的 token。
- 键盘归属：文本框与展开的菜单（`data-own-keys`）收下自己的全部按键；Enter / Space 落在链接或按钮上时保持其原生含义，不再同时打开选中作品。作品墙只在键盘移动后夺取焦点，筛选结果到达、页面加载、刷新或链接打开都不移动焦点；唯一的例外是从作品详情 BACK 回来（见下条）。
- **作品墙分页而非无限滚动，视图状态各有归属**（偏离原型的虚拟滚动；ADR 0003 的「工作台状态不进地址」不延伸到作品墙）：
  - 编号页带总数（ADR 0011 §7），页码条在墙下，只有一页时隐藏；页大小 24 / 48 / 96 / 192 在筛选栏 SIZE 里选。墙是普通网格，封面懒加载（`loading="lazy"`），填满并裁切（`object-fit: cover`），与原型的背景图一致。
  - **地址**持有决定墙上显示什么的一切：媒体库、声优、社团、年龄、标签与模式、FIND、排序、页码、生效的页大小、选中作品。同一个 `?page=3` 在任何地方都是同一段，所以页大小总写进地址；页面对自己地址的改动（导航、BACK、链接）直接流回。筛选、FIND、排序、页大小的改动回到第 1 页，翻页保留筛选，恢复地址不触发切换媒体库的清空。地址超过 64 KiB 时拒绝改动并在筛选栏明示，不悄悄放宽。
  - **历史记录项**持有「从这里打开了哪部作品、墙滚到哪」：打开作品（双击、触屏点按、Enter、FIND）先提交选中作品与返回位置，再导航。BACK 回来时等数据与网格就绪后恢复一次：先恢复滚动，再不滚动地聚焦那部作品；用户在此之前已有点击或按键则不夺焦。没有返回状态（刷新、链接）时只把选中作品滚入视野。
  - **localStorage** 只记页大小偏好，仅在地址既无页码也无页大小时决定首次的页大小。FIND 输入中的草稿、标签弹窗的暂存、展开的菜单留在组件里。
  - 纠正只在数据落定后进行：页码超出末页退到末页；选中作品不在本页（已删除、排序或并发修改把它移走、链接指向别页）时退到本页首部作品，不跨页查找。
- **阶段 3 的换肤规则**：
  - 当前/选中一律反色（`--invert-bg/fg`：全局导航、工作台导航的当前项、菜单的键盘高亮），悬停只到 `--bg-subtle`。菜单的删除项不反色，保留红色，删除永远不像普通选项。
  - 菜单里的单选项与复选项例外：反色留给「已选中」，键盘高亮改为 `--bg-subtle` 加 1px `--wire-strong` 内框；高亮落在已选中行上时，内框换成缩进 2px 的 `--invert-fg` 线，否则反色块上看不出焦点。已选标记是行首 6px ■（行内边距 4px + 14px 标记槽），各行文字因此对齐，也与标题条带的 ■ 同轴。
  - 共享 Button 只取反色与幽灵框（主按钮悬停浮出 3px 框、按下沉入；描边按钮悬停反色），**不带**原型 `.btn` 的擦除动画与左侧 ■ 标：■ 落在按钮外 14px，工作台工具栏的密度放不下。
  - 不再有柔和阴影：浮层用 1px `--wire-strong` 边；下拉菜单另带 4px 幽灵框。模态框不带幽灵框，因为遮罩下框与遮罩之间的底色缝会亮成一条。
  - 双终止线的外缘：作品库、工作集、工作台的顶栏下沿，以及批量计划条、移动端导航条的上沿（`.edge-bottom` / `.edge-top`）。表头下沿用一条 1px `--wire-strong`，即「表格终止线」。
  - 颗粒铺在应用、工作台与侧栏的底材上（`.substrate` / `.substrate-panel`），卡片与行保持平涂。
  - 原生复选框用 `accent-color: --invert-bg`；文本框聚焦时边线换成 `--wire-strong`，不加光环（与 FIND 一致）。
  - 未应用修改的琥珀点落在反色的当前项上时，加一圈 `--invert-fg` 描边，保证深色主题下仍可辨（它同时有 `title`）。
  - 手机上没有全局底栏（原先的两入口底栏已取消）：窄于 641px 时，每个页头最前面是 GlobalMenu（品牌标记），菜单里依次是 NAV（两个全局入口）与 THEME 两组单选。屏幕底边留给页面自己——作品页的播放条与文件机库、工作台的选择操作条——不再与全局导航叠成三层；最外层的安全区由主区域统一承担。桌面仍是侧栏，主题入口是侧栏底部的 ThemeMenu，两处共用同一个 THEME 单选组。ThemeMenu 入口标出当前模式（LIGHT / DARK / AUTO），菜单是单选组，已选项左侧有 ■ 标，与标题条带的 ■ 同轴对齐。作品库页头的 DARK/LIGHT 按钮和工作集移动端的「更多」菜单都已去掉，「添加媒体库」在各宽度下都直接显示。
  - 中文标题与表头去掉字距与大写。工作台的字号（`text-base`、`text-[11px]` 等）不并入五级字阶：密度优先，留作后续。
