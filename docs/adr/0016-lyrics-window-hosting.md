# 0016 歌词窗口的宿主：Document PiP 与桌面壳原生窗口

## 背景

Lyrics Window（见 [CONTEXT.md](../../CONTEXT.md)）要在任何页面跟随正在播放曲目的 Timed Lyrics，并能控制播放器。浏览器侧没有一种悬浮窗口能同时覆盖所有引擎；桌面壳选用 Wails v3，其多窗口都是独立 webview，与主页面不共享 JS realm。Wails 3.0 在各平台提供的窗口能力不对等：Windows 支持透明、置顶与鼠标穿透；Linux GTK4 下透明与鼠标穿透尚未实现，置顶只在 X11 生效。

## 决定

1. **浏览器只走 Document Picture-in-Picture（Chromium 116+）**：窗口内容是普通 Vue 组件，在同一 realm 内挂载并直接读写响应式状态。检测不到该能力时入口隐藏，不提供替代实现。
2. **维护链路 = Chromium + 桌面壳**：Firefox、Safari 不在支持范围；桌面版由壳提供原生窗口。
3. **宿主接缝在 `DesktopAdapter`**：平台标识中性化为 `'browser' | 'desktop'`；`openLyricsWindow` 读取快照、回报命令，返回关闭函数，用户关窗时回调 `onClose`，不支持时返回 null。桌面壳为窗口开一个独立的无边框原生窗口，复用同一 Web 入口、在启动最前按路径分流，只挂载窗口组件；快照与命令走 Wails 的跨窗口事件，壳只负责开关窗口与锁定并回报关闭和锁定状态，不解读快照。
4. **窗口契约按跨 realm 设计**：窗口组件只接收可序列化的快照（作品、曲名、当前行、暂停与前后曲可用性），只发出 `prev | toggle | next` 三种命令；它不读 Pinia、不用路由。当前行在主窗口计算后推送。
5. **窗口是单行滚动的纯展示 + 悬停浮现的顶部控制栏**：不做键盘控制、不做点行跳转。Document PiP 在手机和平板上不可用，功能只面向桌面，因此沿用桌面歌词的惯例，控制栏不占歌词区高度。控制栏兼作拖拽区，并留插槽放宿主操作（关闭、锁定）；宿主操作不进入播放器命令。
6. **平台差异按能力取舍**：浏览器与 Linux 是固定深色底、尽力置顶的窗口；Windows 是透明窗口，文字自带描边与阴影，悬停时衬底，置顶，并可锁定为鼠标穿透；窗口内可切换为页面自绘的深色底，选择只记在本机。锁定后窗口收不到鼠标，只能从主窗口播放栏的歌词入口解锁；窗口关闭即复位锁定。窗口位置与尺寸不记忆。

## 放弃的方案

- **canvas → captureStream → `<video>` 的视频 PiP**：Chromium 与 Safari 可用，但窗口内容是图像，无法交互、需自绘文本排版，后台需另行驱动重绘；为多覆盖一个 Safari 承担一条独立渲染链路，不值得。Firefox 依然不可用。
- **`window.open` 弹窗兜底**：不能置顶，易被拦截，与"悬浮"语义不符。
- **adapter 返回 `Window`/`Document` 让调用方自行挂载**：桌面壳的独立 webview 给不出同 realm 对象。
- **壳中转并缓存快照**：壳要因此理解播放器状态，越过"只做原生宿主操作"的边界；跨窗口事件加一次就绪握手已能补齐首帧。
- **单独的窗口 HTML 入口**：多一份构建配置，换来的包体积收益在按需加载下很小。
- **强制 XWayland 换取 Linux 置顶**：失去原生 Wayland 的缩放与输入，WebKit 渲染路径也随之改变；合成器窗口规则已能满足需要置顶的用户。
- **Windows 系统材质（Mica、Acrylic）**：Mica 在窗口失焦时退为纯色，而悬浮窗口几乎总处于失焦状态；Acrylic 持续模糊背后内容，开销高且不如透明直接。旧版 Windows 上 Wails 还会把材质退化为背后模糊。
- **托盘菜单、全局快捷键或光标热区解锁**：各自引入一块新的原生界面或常驻轮询，主窗口入口已够用。
- **逐字卡拉 OK 填色**：真实库里的 Timed Lyrics 以只有行级时间的翻译歌词为主，逐字填色没有数据来源。

## 后果

- 非 Chromium 浏览器用户没有 Lyrics Window。
- 两个桌面平台的窗口外观与能力不一致：Linux 没有透明与锁定，直到 Wails 的 GTK4 实现补齐后再评估。
- Wayland 没有窗口置顶协议，Linux 桌面壳的 Lyrics Window 不保证悬浮在其他窗口之上；窗口标题固定，用户可用合成器窗口规则置顶（见 [desktop.md](../desktop.md#lyrics-window)）。
- 窗口不止一个后，"关主窗口即退出"需要壳显式保证。
- 若改为支持 Safari 或放宽契约（例如窗口内跳转、键盘控制），重新评估本记录。
