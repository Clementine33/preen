# 0014 存储档与并发上限

## 背景

扫描、后台媒体事实与编码各有自己的 worker 池，默认值是在不同年代、不同存储上分别测出来的。设置页需要让用户就并发做出选择，但逐个 worker 数既无法被用户理解，也无法从本机推广：同一个数字在 NAS 机械盘上受 I/O 延迟约束，在本地 SSD 上却受 CPU 约束，而 CPU 余量又随机器核数变化。

实测显示三类池的瓶颈各不相同：扫描在本地 SSD 热缓存下被单写者的 staging 写入与合并限制，worker 数无可测影响；直连 HDD 冷缓存扫描主要受元数据读盘等待限制，SMB 热缓存扫描则主要受目录访问往返限制。媒体事实在 SSD 上主要消耗 ffprobe 进程的 CPU，在 NAS 上受往返延迟限制；编码在 SSD 上几乎随核数线性扩展，在机械盘上 4 个 worker 后收益递减。

## 决定

1. **存储档是媒体库的属性**：每个媒体库按媒体所在存储标为 HDD 或 SSD 两档之一，机械盘 NAS 归 HDD。档位只回答"该库的磁盘是否为瓶颈"，给出各池在 I/O 侧允许的并发上限。
2. **CPU 余量由后端推导，对所有档位统一生效**：每个受档位约束的池，实际并发 = `min(档位 I/O 上限, C)`，`C` 为后端可见逻辑 CPU 数的固定比例（保留约 1/3 给前台与其他负载）。CPU 部分不随档位变化，也不暴露为设置。后台媒体事实与用户发起的编码共用同一余量，后台任务不得比前台任务更激进。
3. **只有适合按存储档区分上限的池参与档位**：媒体事实与编码参与；扫描并发用于重叠元数据访问等待，HDD/SSD 两档不足以单独预测其收益，保持统一默认；计划生成并发由工作集通用池与轻量任务附加通道固定管理，不随存储档变化。
4. **不向用户开放逐个 worker 数**：用户只选择存储档。具体上限与 CPU 比例是实现常量，随测量调整，不改变本决定。
5. **生效边界与唯一权威**：修改存储档从后续任务开始生效，在途任务保持已确定的宽度；旧工程配置不再覆盖 worker 数，配置示例与读取线路一并移除。存储档推导是并发宽度的唯一用户配置权威。

## 放弃的方案

- **开放各池 worker 数**：用户无从判断合适的值；同一值在不同存储、不同核数下含义相反，测得的最优值不能推广到其他机器。
- **每档写死固定数值（如 SSD 编码 8）**：只是测量机器的结果，在多核机器上偏保守，在低核机器上会占满全部核。
- **SSD 档以全部核数为上限（如媒体事实 `min(16, N)`）**：后台任务会跑满整机，前台浏览并不会抢占它，优先级与编码颠倒。代价是放弃测量机上约 10% 的媒体事实吞吐。
- **扫描 worker 随档位或文件系统变化**：本地 SSD 热缓存测量中 8–32 无可测差异，直连 HDD 冷缓存和 SMB 扫描均受益于并发；保留统一 32 worker，以简单调度覆盖已测场景。
- **自动识别存储设备与拓扑**：跨平台识别 NAS 背后的介质不可靠，单盘部署下也不需要。

## 后果

- 媒体库以 `storage_class` 保存档位，新建库和升级后的已有库默认 HDD；通过现有媒体库读取和更新接口管理。
- 媒体事实一次后台遍历可跨越多个媒体库；每批采用涉及库中最保守的宽度，未归属库存按 HDD，批次开始后不再改变宽度。
- 媒体库存储档及按档推导已接入后端。编码会话在 worker 开始处理时、预检之前固定宽度；排队期间的档位修改会被尚未开始处理的会话读取。
- 旧 `scan.workers`、`execute.max_io_workers` 与 `workset.generation_concurrency` 配置读取已移除；配置文件中遗留这些键会被忽略。
- 未测前台响应性：CPU 余量比例只在 6 核 12 线程机器上验证过，后台任务是否需要更大余量待测；无超线程、大小核等拓扑未测。
- 扫描保持作品间并发、作品内顺序遍历。在 [Btrfs 直连 HDD 冷缓存测量](../issues/archive/library-rescan/evidence-20261025.md)中，1 / 16 / 32 worker 分别约需 119 / 61 / 57 秒，读盘量均约 440 MiB：32 worker 以相近读盘量缩短等待，也给系统与磁盘提供更多请求调度机会。保留这一收益，后续是否降低并发主要看同盘交互响应性。跨文件系统表现、混合负载及具体调度机制仍待验证。
- 测量数据与初始常量依据参见 [ssd-concurrency-measurement.md](../issues/ssd-concurrency-measurement.md)、[library-rescan-measurement.md](../issues/library-rescan-measurement.md) 与 [adr-performance-evidence.md](../issues/adr-performance-evidence.md)。
