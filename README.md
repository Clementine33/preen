# Preen

<img src="frontend/web/public/favicon.svg" alt="Preen Logo" width="96" height="96" />

一个集同人音声媒体库管理、在线播放与工作集批量整理（文件编辑、音频转换、目录重命名）于一体的自托管媒体服务与桌面应用。

## 功能支持

### 媒体库
- 支持添加多个独立的媒体库根目录（可按 HDD / SSD 配置并发策略），自动识别并绑定 `RJ` 作品目录
- 支持从 DLsite 获取作品元数据与主封面，支持配置出站代理
- 自动解析日文原版、简繁中文版本页及多个汉化译制作品之间的多语言版本树与翻译关联链路
- 支持按关键字、社团、声优、官方标签、个人标签、分级、语言、评分、收藏及收听状态等多维度快速筛选与排序作品
- 支持对作品进行打分（1–10 分）、编写评语、打个人标签，以及将作品加入收藏夹或支持拖拽排序的自定义作品合集
- 自动归纳同一作品下的不同演绎版本（如含音效、无音效等目录）与多格式音轨，支持按全局音频格式偏好自动选择播放格式
- 支持在线播放音频与独立视频、浏览高分辨率图片与缩略图，以及在线阅读文本台本
- 支持 `.lrc` 与 `.vtt` 时间轴歌词自动匹配与手动配对，支持点击歌词跳转进度（Docker / 网页端通过浏览器画中画提供悬浮歌词窗）
- 按作品演绎版本独立保存收听进度与听完标记，即使转换音频格式或切换格式偏好也能无缝续播
- 除 Docker 部署版外，还提供开箱即用的桌面客户端，内置并自动托管后台服务，并独享支持透明背景与鼠标穿透的原生桌面悬浮歌词窗

### 文件夹基础编辑
- 媒体库即工作台，支持在库内勾选一批作品文件夹（1–500 个）组成共享工作集，在文件管理、元数据获取、音频转换与目录重命名间直接复用
- 支持在网页端直接浏览作品目录树，实时查看音频格式、码率、时长、图片分辨率及文件大小等媒体属性，并可单独刷新单个作品目录
- 支持对作品目录内的单文件或子文件夹进行在线重命名与目录内移动，自动拦截重名覆盖与越界路径
- 支持一键软删除目录内文件或子文件夹，被删内容按原相对路径移入作品同级的 `Delete/<作品目录>/` 回收目录，方便随时恢复

### 转换
- 采用“先生成计划、审阅后再执行”的可视化工作流，执行前可逐个作品审阅每个音频文件的保留、转换或清理决策
- 支持通过“无音效”路径标签与“其他版本”目录标签自动划分音频分区与独立版本作用域，分别配置各分区的目标输出规格
- 支持为各分区声明期望保留的最终音频形态（无损 `WAV` / `FLAC` 与有损 `MP3` / `AAC` / `Opus` 指定码率），严格以合格无损音频作为转换源
- 提供严格模式与按可用源转换模式，自动识别并提示多源竞争、未知码率及无损源缺失等状态
- 支持全局默认配置、单文件夹独立覆盖与多文件夹批量编辑，被替换或淘汰的旧音频可选择移入 `Delete/` 回收目录（软删除）或直接清理（硬删除）

### 重命名
- 支持使用 `{rj}`、`{title}`、`{circle}`、`{voice_actors}`、`{language}`、`{release_date}` 占位符模板，根据作品元数据批量生成文件夹重命名方案
- 支持自定义多声优分隔符，并提供一键剔除标题中 `【…】`、`~…~` / `～…～`、`《…》` 括注内容的可选过滤开关
- 支持为单个作品文件夹单独指定目标名称，或通过修改目标名称中的 `RJ` 编号在执行重命名时同步改绑作品

## 设置与配置

### 服务端配置（`config.json` / 环境变量）
- `server.allow_lan`（或 `--allow-lan`）：控制服务仅监听本机 `127.0.0.1`（`false`）还是允许局域网访问 `0.0.0.0`（`true`）
- `server.port`（或 `--port`）：指定后端 HTTP 监听端口（`0` 为本地模式下系统随机分配，局域网模式须指定固定端口）
- `server.token`（或环境变量 `PREEN_TOKEN`）：设置登录网页端及调用 API 的共享访问密钥（局域网模式必填，环境变量优先）
- `prune.no_effect_tags` / `prune.other_tags`：配置“无音效”与“其他版本”两组默认分类标签，修改后会影响转换任务的默认初始标签值
- `PREEN_DATA_DIR`（环境变量）：指定数据库文件与 `config.json` 的存储目录
- `PREEN_LOG_LEVEL`（环境变量）：设置后端运行日志级别（支持 `debug`、`info`、`warn`、`error`，默认 `info`）
