# 前端设计语言

本文件写的是 YoRHa 视觉语言的使用规则：什么场合用什么，以及为什么这样用。具体数值（色值、尺寸、时长）只在 `src/theme-yorha.css`（原生 tokens 与原语类）和 `src/style.css`（shadcn 语义层映射与对比度记录）中维护，这里不抄录。代码组织与状态归属见 [AGENTS.md](AGENTS.md)。

## 1. 原则：底座同构，业务分层

全站共享同一套 tokens、字体矩阵和原语，没有哪一页自成一套。在这个底座上，两类页面各说自己的语言：

- **作品区**（作品墙、作品详情、播放条）是展陈：完整的 HUD 语法、明朝体标题和动效。
- **工作台**（目录树、计划审阅、批量编辑表单）是工具：只换容器观感、表格终止线、表单控件、按钮反色和选中高亮，不推翻原有的交互流程，也不套用展陈动效。密度优先于视觉一致。

## 2. 来源与改色

- 唯一的视觉来源是评审通过的原型 `work-wall-v5-2-yorha-refined.html`（open-design 项目 dorganizer-plan-7686，在仓库外）。`theme-yorha.css` 里的数值是用户确认过的决定，不是可以随手调整的起点。
- 改任何颜色之前都要重新验证对比度：正文 ≥ 4.5:1，控件边界和焦点指示 ≥ 3:1（WCAG 1.4.11）。结果记录在 `style.css` 的对比度注释里。
- 原型以外只多了一个 token：`--wire-control`。原型的 `--wire-mid` 约为 2.4:1，作装饰线够用，作控件边界不达标，所以输入框和控件的边线用 `--wire-control`，装饰线继续用 `--wire-mid`。
- 原型里的 `--accent` 在本仓改名为 `--now`，因为 `--accent` 在 shadcn 语义里表示悬停面，两种含义不能共用一个名字。

## 3. 线与面

- **不用柔和阴影。** 浮层的边界是 1px `--wire-strong`。下拉菜单再加一个偏移 4px 的幽灵框；模态框和抽屉不加，因为遮罩下框与遮罩之间会露出一条亮缝。
- **双终止线只出现在外缘**：页头下沿（`.edge-bottom`），以及底部条的上沿（`.edge-top`），比如批量计划条和移动端导航条。内部的线一律 1px。表头下沿用一条 1px `--wire-strong`，作为表格终止线。
- **直角。** 菜单、浮层、模态框都用 `rounded-none`；其余控件的圆角不超过 `--radius-*` 定义的最大值。
- **滚动条**全站统一为扁平方形细线：不显示轨道和箭头。组件要隐藏滚动条时只能设 `scrollbar-width: none`，不要设 `thin` 或颜色，否则 Chromium 会忽略我们定义的伪元素样式。

## 4. 材质

- **颗粒**只铺在底材上：应用、工作台和侧栏的背景（`.substrate` / `.substrate-panel`）。卡片和行保持平涂；封面是不透明图像，任何时候都不加颗粒。
- **45° 排线**（`.hatch`）只用于空状态，比如缺失的封面、离线的媒体库标签。
- **封面**固定 4:3，最大不超过原生尺寸，填满并裁切。

## 5. 反色与选中

- 当前项和选中项一律反色（`--invert-bg/fg`），包括全局导航和工作台导航的当前项，以及菜单的键盘高亮。悬停只变到 `--bg-subtle`。
- **菜单里的单选项和复选项是例外**：反色只留给「已选中」。键盘高亮改成 `--bg-subtle` 加 1px `--wire-strong` 内框；如果高亮落在已选中的行上，内框换成 `--invert-fg` 线，否则在反色块上看不出焦点。已选标记是行首的 6px ■。
- **删除项**在菜单里保持红色，不反色，让删除永远不像普通选项。
- **筛选与排序**：设了值的筛选显示为按下的标签（反色），排序下拉不反色。
- **共享 Button** 只用反色和幽灵框：主按钮悬停时浮出 3px 框，按下时沉进去；描边按钮悬停时反色。它不带原型 `.btn` 的擦除动画和左侧 ■ 标，因为 ■ 落在按钮外 14px，工作台工具栏的密度放不下。`.btn` 原语只在作品区使用。
- 原生复选框和单选框用 `accent-color: --invert-bg`。文本框聚焦时边线换成 `--wire-strong`，不加光环。
- 状态角色（success / warning / danger / info）保持各自的字面色值，不并入 YoRHa 色板，因为它们编码的是领域状态。状态不能只靠颜色表达，必须同时有文字、图标或 `title`。未应用修改的琥珀点落在反色的当前项上时，要加一圈 `--invert-fg` 描边。
- 陶土红（`--now`）用于「正在播放」：NOW 标、播放中的音轨标记、状态点、浅色主题下的激光。它不用作悬停色或强调色。

## 6. 标签与字体

- **三层字体矩阵**：
  - `--font-mincho`（明朝体）：只用于作品标题，即作品墙卡片标题和详情页展台标题，以及分页条上的当前页码。不用在任何界面标题上。
  - `--font-ui`：正文、元数据、表单，以及全部界面标题（页面 h1/h2、弹窗与抽屉标题、目录树节点）。`--font-heading` 指向它。中文字体必须排在字体栈最前：字体回退按家族匹配，日文字体排在前面会拿下所有中日共用汉字，显示成日文字形。
  - `--font-mono`：标签、RJ 号、时间等遥测数字，一律用等宽数字（`tabular-nums`）。
  - `--font-ja` 只用于详情页 `lang="ja"` 的片段。
- **标签语法（`.lbl`）**：只有大写拉丁字母的 mono 标签加字距；日文和中文的标题、表头不加字距，也不转大写。标签和值之间用空格分隔，不用 `::`。`·` 只出现在按键提示和音轨总数里。
- **标题条带（`.strip`）**：以 6px ■ 开头，用作 INSPECT、TRACKLIST 等区块的标题。条带、菜单已选标记和 ThemeMenu 里的 ■ 保持同一条轴线。

## 7. 尺度与动效

- **字号**：五级字阶，基于 4px 基线；间距取 4px 的倍数。工作台的密度字号（`text-[11px]` 等）暂不并入五级字阶，这是为了密度有意保留的例外。
- **两套动效 token 并行**：YoRHa 的 `--dur-*` / `--ease-*` 给作品区用；工作台继续用 `--motion-*` 和密度 token（`--row-h` 等）。各页面按自己的语言取用，不要混用。
- **展陈动效**要短而克制。例如分页条：当前页两侧各有一枚 ❖，翻页时这对 ❖ 以断奏方式滑行，全程控制在约 250ms 内；不加边框、端饰和读数。
- **连续切换降级**：每次切换都重放的展陈动效（选中态擦入、封面擦入、乱码标题、扫描换图、翻页擦入），在连续切换时立即完成：相邻两次切换间隔不足 800ms 时累计，第 3 次起降级，停下 800ms 后恢复。计数归发出切换的那一层（`useSwitchBurst`）。

## 8. 布局与移动端

- 应用宽度大于 640px 时，左侧是 64px 的图标导航栏，主题入口是导航栏底部的 ThemeMenu。宽度不大于 640px 时没有全局底栏，每个页头的最前面是 GlobalMenu（品牌标记），菜单里依次是导航和主题两组。这个切换完全由 CSS 完成（`style.css` 里的 `rail` 变体）。
- 手机屏幕的底边留给页面自己，比如作品页的播放条、工作台的选择操作条，不和全局导航叠在一起。最外层的安全区由主区域统一处理。
- 触屏设备（`pointer: coarse`）用更大的触控热区：播放条加高，不显示音量控件，改用设备自身的音量。

## 9. 可访问性

- 用户开启 `prefers-reduced-motion` 时，全站所有过渡和动画立即完成，没有例外。工作台的 `--motion-*` 也一并归零。
- 焦点必须始终可见：焦点指示用 `--wire-strong`（`--ring`）。
- 文本框和展开的菜单（`data-own-keys`）自己处理全部按键。焦点落在链接或按钮上时，Enter 和 Space 保持原生含义。焦点只在用户用键盘移动时才转移，数据到达、页面加载或刷新都不抢焦点。
