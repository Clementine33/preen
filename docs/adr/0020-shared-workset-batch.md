# 0020 工作集共享一个文件夹批次

用户希望选一次文件夹，转换、重命名和元数据刷新复用同一批次。每个媒体库只保留
一个当前 workset，成员范围独立于 Task，允许没有音频的已扫描作品根。数据库唯一
约束从 `(library_id, operation_type)` 收窄为 `library_id`，workset 不再保存 Task 类型。

创建批次初始化所有已注册 Task 的独立草稿，复用部署级公共设置。各 Task 仍按
`(workset_id, operation_type)` 持有版本、参与范围、当前计划与执行结果；一个 Task
生成计划不覆盖其他 Task。重命名更新共享成员的路径及显示名称，成员 ID 保持稳定，
冻结计划仍由各 Task 判断新鲜度。

概览只有一个“设为工作集批次”入口，选完后由各 Task 页面复用。替换明确清除所有
Task 的成员设置、计划和结果；任一 Task 有 queued/running 会话时都拒绝替换。
既有按 Task 的 current HTTP 入口继续可用，但读取与替换的是同一个共享批次，
幂等请求的身份不包含入口 Task。开发 schema 与未发布初始迁移同步修改，现有开发
库仍遵循 ADR 0013 的显式重建规则，不自动修改用户数据库。

本记录替代 [ADR 0001 §1](0001-library-workbench-and-processing-record.md) 中
“每操作一条记录、只初始化所请求操作”的归属决定；其并发、准入、快照、保留和
删除规则继续适用，其中“一份当前计划”按每个操作解释。

拒绝保留各 Task 的独立批次并复制选择：范围会分叉，仍需要重复选取与同步。
拒绝共享一份草稿或计划：Task 的策略、输入事实和结果不同，不能互相覆盖。
